# 国际日期变更线 · 3D 教学演示

一个可以在浏览器中直接打开的 3D 交互式教学页面，用太空中的地球直观演示**国际日期变更线（International Date Line）**的工作原理：为什么地球上同时存在两个日期、新的一天如何诞生并扫过全球。

纯静态页面、完全离线可用，无需构建、无需服务器，双击 `index.html` 即可运行，也可直接部署到 GitHub Pages。

## 功能特性

- **太空场景**：星空背景、太阳及光照，地球明暗（晨昏线）严格由地日几何关系决定，与观察视角无关
- **真实地球自转**：大陆、海洋贴图与经纬网（每 15° 一条经线 = 一个时区）一起绕地轴旋转，速度可调（1 秒 = 15 分钟 / 1 小时 / 4 小时）
- **红蓝双色日期分区**：按日期的奇偶交替染色，连续变化、无突变，仅用于区分相邻两天（无新旧含义）；左上角实时显示两种颜色各自对应的日期
- **两条日界线**：
  - 白线 = 国际日期变更线（约沿 180° 经线），钉在地球表面、随地球自转
  - 蓝线 = 0:00 经线（自然日界线），在空间中固定于背阳一侧，地球从它下面转过
- **时刻标签**：正午 12:00 / 子夜 0:00 / 日出 6:00 / 日落 18:00，固定在相对太阳的空间方位上
- **定位格林威治**：相机锁定格林威治天文台（0°, 51.5°N）上空并跟随自转，实时显示当地时间和日期（0° 经线的地方时即 UTC）
- **自由交互**：拖动旋转视角、滚轮缩放、UTC 时间滑块（可跨天连续拖动）、相机自动环绕

start index.html       # Windows

## 课堂演示建议

1. 开「1 秒 = 4 小时」档自转：观察新的一天如何从国际日期变更线处"诞生"，逐渐扩大扫过全球
2. 拖到 UTC 12:00 附近：两条日界线重合，全球同属一天
3. 定位格林威治 + 自转演示：盯着一个地点经历日出→正午→日落→子夜，看它的日期在 0:00 经线扫过时翻篇
4. 对比两条线：白线跟着地球转，蓝线不动——一个是人为规定，一个是自然时刻

## 技术说明

- [Three.js r128](https://github.com/mrdoob/three.js/)（MIT License）+ OrbitControls，本地引用，无 CDN 依赖
- 地球贴图来自 Three.js 官方示例（`earth_atmos_2048.jpg`），已内嵌为 base64，绕过 `file://` 协议的 CORS 限制
- 自定义 ShaderMaterial：
  - 世界空间法线 × 太阳方向 → 昼夜明暗
  - `floor(UTC 天数 + 经度/360)` → 每个点的本地日期，按奇偶交替染色（该公式天然包含两条日界线的规则）
- 内部时间采用连续累计分钟数（可跨天），保证颜色与自转无任何跳变
